本模组的大部分 UI 遵循类似的设计模式。

主要导航按键：Tab 前进，Shift + Tab 后退。

Control + Tab 切换主标签页。

Control + Shift + Tab 反向切换主标签页。

E 关闭当前 UI 或返回上一级。

K 提供关于当前焦点对象的详细信息。

Y 在某些 UI 中显示物品的所有属性。

Shift + / 打开帮助菜单。

搜索通常通过 Control + F 启用。

按住 Shift 进行向下/向后导航。

按住 Control 进行快速操作如智能插入。

大多数 UI 支持鼠标右键查看更多详情。

使用方向键在列表项目中移动。

空格键通常在表单中触发默认操作。

Enter 确认选择或进入子菜单。

Escape 关闭当前对话框。

Backspace 返回上级或清除输入。

Delete 删除选中的项目。

Home 跳到列表开头，End 跳到结尾。

Page Up/Down 分页移动。

有些 UI 有额外的快捷键组合。

遇到问题时按 Shift + / 查看上下文帮助。

详细的按键映射请参考 mod 文档。
