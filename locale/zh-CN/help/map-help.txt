这是地图视图，允许你探索所在的地表。请注意此菜单具有上下文相关性，会对有特殊交互的项目显示更多信息。这些信息会显示在此消息上方，方便你查找。

以下是基本控制的简要概述。有关完整的控制文档，请参考模组说明文件和原版异星工厂 wiki。

并非所有按键都由本模组提供。异星工厂本身有很多未涵盖的按键。

你有一个光标和一个角色。光标就像鼠标一样。角色就是你的身体。

光标和角色是完全独立的，但角色必须靠近物体才能建造或配置它们。在原版中大约是10格距离。

使用方向键行走。

按 W、A、S、D 移动光标。

你可以用 Shift + T 传送。这是作弊功能，但很多玩家认为这很公平，因为我们在其他方面更慢。

当光标在一个实体上时，该实体被选中。

按 K 获取关于选中实体或手中物品的更多信息。

右方括号 ] 可提供关于选中实体的更多详细信息。

按 Q 清空手部或执行取样器操作。按 Shift + Q 读取手中物品。

按 Control + [ 将手中的整堆物品放入选中的实体。

Control + ] 放入半堆。

Z 只放下一件物品。

通过把角色移到物品旁边按住 F 来拾取散落在地上的物品，或者用 X 键将其拆掉。

如果想从传送带上拿东西，只能按住 F；用 X 会直接拆掉传送带。

按 J 将光标移回角色位置，按 I 可切换行走时光标是否始终向前移动一格。

在光标移动键（W/A/S/D）上按住 Shift 可以沿指定方向快速移动最多 100 格，遇到重要变化时会提前停下。

按住 Control 配合光标键可以按照手中物品的宽度或高度移动光标，方便快速排成直线。

按左方括号 [ 放置物品。

按住 Shift + 左方括号可放置预告（ghost）。

按住 X 进行开采。

按 R 顺时针旋转物品。旋转的是手中物品还是当前选中的实体，取决于手中是否有物品。

按住 Shift + R 逆时针旋转。

H 和 V 分别用于水平翻转和垂直翻转。翻转与旋转 180 度并不完全相同。

从这个界面可以进入多种 UI。

按 E 打开主菜单（背包、制作、研究等），通常称为"主菜单"。

按 Alt + V 打开快捷旅行菜单。

按 Alt + W 打开世界菜单，可设置火车警报及其他功能。

在解锁物流机器人后，按 Control + Alt + L 打开某个物品的物流界面。

用左方括号 [ 点击实体即可打开其配置界面。注意有时需要先将手清空，以免与"快速替换"功能混淆（例如用更好的箱子覆盖更差的箱子时会自动替换）。

本模组提供了一些轻量级辅助功能，帮助你定位方向。

按 Shift + B 在当前光标位置放置书签，按 B 可将光标跳回该书签处。

标尺呈十字形，当你穿过十字任意一条臂时会发出音频提示。

按 Control + Alt + B 设置标尺。

设置完成后四处走动并移动光标感受它的工作原理。

按 Control + Shift + B 清除标尺。

建造锁定是一个在你角色奔跑时自动在身后放置物品的功能。

对于放置长条传送带这类操作特别有用。

部分实体有特殊的建造锁定行为。最重要的是传送带，它会按照你奔跑的方向自动朝向。

按 Control + B 启用建造锁定。

如果撞上障碍物，建造锁定会自动关闭，因为引擎会将你推离原本规划的路线。

同时使用建造锁定和标尺可以快速铺设长距离的传送带和管道，非常实用。

以下是将工具放入手中的关键按键：

按 Control + C 获取复制工具。

按 Control + X 获取切除工具。

按 Control + V 获得基于上次切除或复制内容的临时蓝图。

按 Alt + B 获取永久空白蓝图。

按 Alt + D 获取拆除规划器。

按 Alt + U 获取升级规划器。

按 Control + Alt + Shift + B 获取蓝图书。

有关驾驶、高级功能和战斗相关的控制说明，请参阅 GitHub 上的模组文档。
