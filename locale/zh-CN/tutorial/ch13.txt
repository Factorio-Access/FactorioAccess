教程给了你示例蓝图。是时候学习自己制作蓝图了。本章重要但也可选，想回头补也行。

异星工厂有三种统称规划师的物品：拆除规划师、升级规划师和蓝图。三种工作方式相同：手持其一，点击矩形两角选定区域，然后执行对应操作。

升级和拆除规划师配合大光标使用时会作用于光标覆盖的所有对象，适合选择性清理区域而无需精确计算四角，比如清理森林。

获取升级规划师按 Alt + U，拆除按 Alt + D，蓝图按 Alt + B。

使用升级规划师时默认标记所有可升级对象：传送带升下一级，机械臂升为快速型等。我们通过右键暴露有限形式的明眼版配置界面。

拆除规划师标记待拆区域，标记后对象停止运作等待移除。两种情况下对标记对象调用巡航控制即可执行动作。但已知升级传送带有难以修复的 bug 偶尔遗漏片段，解锁建筑机器人前最好沿预期升级过的传送带用光标跳过检查一遍。

两者都是临时性的，可存入物品栏，但按 Q 就消失。修改过配置则视为永久保留，改回默认也算修改，删除需按 Control + Backspace。选择第二个点时按住 Shift 可取消区域内所有拆除或升级指令。

升级/拆除规划师的配置仍在积极开发中，自定义配置支持维护带宽有限，目前已知有 bug 和不稳定因素，请自行斟酌使用。

回到蓝图。你已学会使用但还不知道怎么做。与其他规划师一样选中两角创建蓝图，但这次保存数据而非执行。第一次按 Alt + B 获得空白蓝图，暂时性；选定范围后才变为永久，清空手部后进入物品栏。

蓝图也有配置菜单。手持蓝图且所有 UI 关闭时右键打开。可以设置名称和描述、导出到剪贴板，也可导入——粘贴字符串后按 Enter 覆盖当前数据。

要删除规划师：手持且所有 UI 关闭时，或在物品栏中选择它，然后按 Control + Backspace（危险删除），用于不可撤销的操作。地图上危险删除作用于手中对象，UI 中作用于选中对象；不支持时无论手中有什么都不会发生。

虽然你可能尚未做过且很久以后才会做，但模组支持放置地砖。此时要注意一个额外功能：默认蓝图不包含地砖，除非周围无建筑；以右键结束选择可弹出含复选框的菜单，其中"始终包含地砖"默认关闭。除地砖外还支持载具中的燃料等后期更有用的内容。与升级/拆除规划师不同此界面完整且稳定。

蓝图未整理是个问题——无法访问蓝图库始终占用槽位。明眼玩家把蓝图放入蓝图书，模组也支持。书仍占一个槽但可装任意数量蓝图；对明眼玩家而言大部分时间完全不占槽。获取书按 Control + Alt + Shift + B。

书的界面在第一标签页下有两个子标签：显示书内蓝图和操作书本本身。和蓝图一样书可以命名和导出。在设置行中使用"向右移动并点击添加库存中的蓝图"可将蓝图移入书中。书中每个蓝图右侧有操控命令；按 Shift + W/S 可上下拖动调整顺序。用书建造略有不同：书有"当前激活蓝图"概念，通过在菜单中点击设定。想知道地图上哪个处于激活状态按逗号；不打开书循环浏览按 M 和句点。这三个键你在分拣器 UI 中也见过；模组用 M、逗号、句点作为上下文敏感按键后续还会多次出现尤其在火车和电路网络中。你也可以把升级和拆除规划师放进书中切换到它会当作手持使用但对默认规划师用处不大可通过 alpha 级配置对话框或从明眼玩家处导入字符串建立其他设置的规划师库。最后书及其他规划师类物品可放到快捷栏但与明眼玩家不同仍占用物品栏槽位遗憾的是目前无法把书内的蓝图直接放到快捷栏。
