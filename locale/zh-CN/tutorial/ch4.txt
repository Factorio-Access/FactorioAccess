既然你能放置建筑了，现在是学习游戏核心系统的时候了。本章教你 UI 层级、如何查看科技、如何合成物品，以及如何在物品栏之间转移物品。你将通过合成木箱来改进你的燃烧式采矿钻。

主菜单（E）包含多个标签页。还有世界菜单（Alt + W）和模组配置菜单（Control + Alt + Shift + M）。

后两者暂时不重要，我们不多讨论。

模组 UI 分为两级层次结构。

顶级是标签页，如"物品栏"、"合成"和"研究"。用 Control + Tab 和 Control + Shift + Tab 在这些之间导航。

下一级是子标签页或控件，用 Tab 和 Shift + Tab 导航。比如在物品栏标签页里，这就是该建筑的每个可用物品栏。

UI 还提供帮助系统，按 Shift + / 打开。按 E 关闭帮助，回到之前的 UI。

还有两个重要的按键。K 提供聚焦对象的详细信息（如果有），Control + WASD 可向指定方向尽可能远地移动。例如 Control + W 是菜单顶部。

我们先讨论研究。虽然合成能修好你的钻头，但研究告诉你为什么这很重要以及目标是什么。

打开主菜单，进入研究标签页。由三行组成，从上到下分别是：可研究的、已锁定的、已研究过的。

用 W 和 S 切换行，A 和 D 浏览行内内容。

我们的许多 UI 都采用这种非直观的形状，这样你就不必滚动长菜单。

幸运的是，每个 UI 都像之前搜索物品栏一样支持搜索。

现在你有两个可研究的科技：蒸汽动力和电子学。

异星工厂有两种科技，一种是你可以选择的，另一种是自动解锁的。当前两个可选科技都有解锁条件而非科学包需求。按 K 查看具体内容。

电子学的条件是"合成 10 个普通品质的铜板"，蒸汽动力的条件是"合成 50 个普通品质的铁板"。

品质是太空时代的内容。在基础游戏中你不可能找到比普通更好的品质。

现在我们知道了需要什么。怎么得到呢？返回一个标签页到合成标签页，搜索 plate。

如果点击任意板类配方，游戏会提示你不能合成！因为这些必须在机器中进行。

要查看能在哪些机器中合成某物，按 K。这会同时显示所需材料。

你可能还想知道配方的产物有什么用。按 Y 查看它属于什么类型以及有什么属性。

我们不能轻易筛选出你已有的机器，但可以逐个检查。你会发现这种情况下你有的是石炉。

你开局就有一个，而石矿在这章早期之所以有用，是因为你现在可以用它做出更多。

好了，回到修复燃烧式采矿钻。石炉需要煤才能运行。煤和矿石进去，板材出来。这在合成菜单中不明显，而且电炉不需要煤。一般而言，你可以看设备是否抱怨没燃料，或者检查它有没有燃料槽。

如果煤没有稳定供应，就无法推进。

我们用木箱来解决。用扫描器找一棵树，让巡航控制替你挖几棵。

这会给你木材。几乎没有东西用到木材，所以不用担心耗尽。

有了木材后，就可以合成木箱了。

之前你找到了燃烧式采矿钻吐出煤的地方。回去那里（可以用扫描器找到钻头），在那个格子上放置箱子。

如果箱子位置正确且钻头有燃料，它现在开始缓慢地向箱子填充煤炭。

很快我们会讨论更高效的维持燃烧钻的方法。现在重要的是要知道它产出的煤多于消耗的煤。

这意味着你可以把钻出来的煤放回钻头让它持续运行。

你有几种从箱子取出物品的方法。

第一种和第二种是 Control 左键/右键，就像做智能插入，但这次用手为空的状态。此时游戏会智能地取走物品。对于箱子来说就是"取出全部内容"。

你可以通过按 Q 清空手部。Q 在手为空时有第二功能，我们稍后讨论。如果提示放到了你手里，再按一次 Q。

第三种是打开箱子本身的物品栏。你可以点击物品把手中拿到，然后按 Q 把物品放入你的物品栏。或者 Shift + 左键 一次性移动一整格，Shift + 右键 移动半格。

我们称之为同级物品栏，反向同样适用。如果你探索箱子的可用标签页，会看到另一个是你的物品栏。Shift 点击控件在你的物品栏中也能把物品移到箱子。

你现在的责任是留意这套装置。偶尔钻头需要更多燃料。当它用完时需要从箱子取煤放入钻头。很快我们会有不依赖定期检查的解决方案。

在结束本章之前，你应该知道你现在正在产生污染。本教程对此着墨不多，因为你本该在和平模式下，但它即使在和平模式中也 matters。

随着游戏推进，你的工厂会产生污染。具体数量取决于你建造的机器数量和当时运行的机器数。仅这一个钻头产生的污染非常少且缓慢，但随着你建造更多，产出速度越来越快。

敌人生成器会根据污染变强。如果你不在和平模式，它们最终会来攻击你。

污染像云一样从机器处真实扩散。按 Shift + U 可查看光标处的污染量。
