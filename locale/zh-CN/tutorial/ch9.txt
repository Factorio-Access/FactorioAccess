在掌握传送带和机械臂的基础后，现在学习如何构建长直线。本章教你三个工具：Build Lock（边移动边建造）、音频标尺（精确定位和测量），以及剪贴板蓝图（快速复制粘贴结构）。

Build Lock 最重要。开启后，角色每移动一步都会在其身后自动建造。

光标的移动也会尝试在光标背后一格建造（比如按一次键在当前格建造再移动），但由于游戏 API 限制这不太好用，最好避免。

行走一般没什么优势，但有一个例外：沿着已经清理完障碍物的路线行走。

如果你知道要铺设 200 段传送带成一条直线，可以开启 Build Lock，用方向键跑出这条线，然后修整两端。两端通常会比你想要的略长几格。

使用 Build Lock：按 Control + B 切换开关。当手部为空、再次按 Control + B，或被障碍物意外推开时会自动关闭。

多数情况下 Build Lock 等同于手工沿线路放置。但有两个重要情况不同，因为我们提供了更便捷的行为。

第一种是传送带。开启时传送带会跟随你的角色移动并按角色的转向自动转弯。你往哪个方向跑，传送带就跟到哪。通常不建议用来拐弯，但如果这次不需要精确也可以。

第二种是电线杆。我们在最大连接距离处放置电线杆，连接到链上最后一根。所以小型电线杆第一次立即放置，之后每隔 7 格放置一根。

上一章末尾我们设置了自维持煤矿，但蒸汽机和锅炉通常在离水近的地方，所以很远。现在有工具可以方便地建立连线了。

规划好长线位置，开启 Build Lock 跑过去，然后调整两端到正确位置。如果用传送带版本的可持续煤矿，输入端需要在传送带上，输出端要在距离锅炉一格以内以便机械臂能够到。

如果放置正确，现在就有了一个跑到钻头耗尽煤为止的供电装置。这让机械臂和电动采矿钻得以使用。稍后会细讲电动采矿钻。

你可能在意精度。有两个辅助工具，一个来自原版，一个来自模组。

模组提供音频标尺。按 Control + Alt + B 放置，Alt + Shift + B 清除。

当光标与音频标尺对齐时你会听到蜂鸣。两个低频音表示距线条一格以内，高频音表示完美对齐。实际定位点发出的是咔嗒声。

建议花点时间放置一个音频标尺并四处走动，感受它的投影形状。它形成一个十字交叉延伸至无限远。

音频标尺与光标跳过配合使用。光标跳过时会在碰到音频标尺时停下，而不是越过它。

也与角色配合。角色穿过标尺也会触发蜂鸣。

它不会关闭 Build Lock。我们无法知道你放标尺是不是为了关掉它，所以碰到后你自己负责停步。

具体例子：在锅炉处放置音频标尺，用光标跳过查看距离，然后跑传送带直到碰到标尺再转向锅炉。

原版提供剪贴板，我们通过接口与之交互。你已经用过蓝图。剪贴板类似，但它生成的蓝图在按 Q 后自动销毁。

使用方法：按 Control + C 进入复制模式，然后点击两个点。模组会把框内的所有内容转为蓝图。和其他蓝图一样，它可以旋转。

要保留一份拷贝，可以打开物品栏点击空格。小心：原版和模组都会在用手部物品交换时保留蓝图。

剪切同理，但增加了一个新状态：标记拆解。被标记为拆解的建筑会被后期解锁的自动化工具拆除，也可以由 KK 拆除并在其上放置新蓝图。

剪切会标记框内所有对象进行拆除，然后给你生成包含被拆内容的蓝图。

可以用剪切来整体平移大型装置几格——只需放置蓝图并调用 KK。

像传统剪贴板一样，按 Control + V 可以恢复剪贴板内容。

有个边缘情况要注意：明眼玩家从建筑的中央而非西北角开始构建。因此模组必须根据蓝图内的内容计算尺寸。如果在蓝图中只放一个实体却选了 1000×1000 的区域，最终只有这一个实体。如果是箱子，蓝图就是 1×1！

也可能某个角落没有实体。举例：四个角各放一个箱子，删掉西北角的箱子然后蓝图化。结果蓝图仍是 4×4，放置时光标恰好在空缺处！

这些点非常重要。如果需要强制蓝图固定大小，可以在四个角放廉价木箱辅助。

下面展示如何用这个工具铺线：

放置 5 段传送带，假设朝东。按 Control + C，点击第一段传送带，按 Shift + D 跳到东端再点击。此时手里得到 5 段传送带的蓝图。

现在可以把蓝图放在传送带末端外一格的位置，光标跳过穿过幽灵，继续放置，反复多次。每次延长 5 格。

蓝图可以不建幽灵直接用，你可以做出 20 段的长线再整体复制，一次放 20 段。

还有更简单的——模组的"按预览跳过"功能。不按 Shift+WASD，而是按 Control+WASD。

按此方式，每次移动的步长等于你手中对象的宽度或高度，不论地面如何。也尊重旋转。

所以不用按很多键，只需连续 Control+D 点击，重复即可。

放置蓝图时角色距离无关紧要，因为只是在放置幽灵。建成长线后，KK 可以替你完成剩余部分的建造。

蓝图会自动处理树木——把它们标记为拆解。所以 KK 建造时会先清理区域。

有了这些工具，你应该能完成供电设施了。

电力不通电就没有用处。目前你能合成的唯一一定会耗电的物品是无障碍雷达（accessibility radar）。做一个用它测试供电系统。我们稍后会解释它的用途，但尽早放置并保持常开很重要。

右键点击电线杆可以获得更多信息，包括满意度——衡量你是否满足机器电力需求的抽象指标。现在是时候搞清楚正常工作时是什么样子的。

很快你需要扩展电力输出，也就是连更多锅炉和蒸汽机。如果知道正常工作状态，更容易识别问题或判断是否需要更多电力。
